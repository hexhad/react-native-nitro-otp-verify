# Security Policy

## Supported versions

Only the latest published version of `react-native-nitro-otp-verify` receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.
Report privately via [GitHub Security Advisories](https://github.com/hexhad/react-native-nitro-otp-verify/security/advisories/new).
You should receive a response within 7 days.
